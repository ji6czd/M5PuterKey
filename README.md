# M5CardPuter Portable BLE Keyboard

名前の通り、
[M5Stack CardPuter]()
をBLEキーボードにする簡単なプログラムです。

## ビルド

PlatformIOのプロジェクトにしています。おそらく問題なくビルドできると思います。

## 使い方

このキーボードには４つのモードがあります。FNキーで切り替えます。起動直後はNormalモードです。押すたびに

* Cursor
* Numeric
* Media
* Normal

と切り替わります。Ctrlキーを押した直後にFNキーを押すとNormalモードになります。

各モードでは、キーボードがモードに応じたキー配列になります。

### Normalモード

一般的QWERTYです。Ctrl, Alt, Shiftキーは、押すと次の一文字を入力されるまでロックされます。

### Cursorモード

カーソルを動かすモードです。キーボードの右下部分に割り当てています。

### Numericモード

主に電話の発信をすることを意図しています。キーボード右側部分に割り当てています。

### Mediaモード

音楽の再生・停止、トラック送り・戻しをサポートしています。キーボード右上に割り当てています。
